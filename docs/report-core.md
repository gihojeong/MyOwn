# report-core — 4개 리포트 회차의 공용 규격

작성 2026-10-10. 이 문서는 ★루틴 프롬프트에서 뺀 공용 내용★을 모아 둔 곳이다.
프롬프트가 길어져 입력창에서 앞부분이 잘려 저장되는 사고가 나서(2026-10-10 실측:
개장전 2,611자·주간 13,240자 유실) 중복을 여기로 내렸다.

## [C0] 지위와 선후관계

읽는 순서와 우선순위다. 위가 이긴다.

1. `report_scoreboard` 의 `[인프라]` 절 — ★환경 상태(자격증명·API·수집기)의 정본★. 매 회차가 갱신한다.
2. `docs/common-report-guide.md` — ★서술 방식·용어·부록·예측력 복기·시장을 보는 틀★의 정본.
3. ★이 문서★ — 환경 확정 사실 · 기계적 제약(자격증명·오류코드·수집 절차·Drive·이메일 HTML).
   ★리포트 형식과 포트폴리오는 2026-10-11 에 가이드 [G9]·[G10] 으로 이관됐다.★
4. `docs/trigger-prompts/{premarket,close,weekly}.live-*.txt` — 회차별 수집 항목·해석 규율 전문.
   `docs/collection-contract.md` · `docs/kiwoom-report-playbook.md` — 수집·계산 규격.
5. 루틴 프롬프트 — 회차 식별 · 납기 · 위 문서로의 포인터만 담는다.

프롬프트와 이 문서가 어긋나면 이 문서가 이긴다. 이 문서와 장부 `[인프라]` 절이 어긋나면 장부가 이긴다.

### [E3] 키움 WAF가 User-Agent 를 본다

- urllib 기본 UA 는 막힌다 — `HTTP 400 "Request Blocked"` (본문이 HTML) 로 온다.
  실측: UA 없음 · `Python-urllib/3.11` → 차단 / `kiwoom-collect/1.0` · `Mozilla/5.0` → 정상.
- 수집기는 UA 를 박아 두고 있어 문제없다. ★직접 호출하는 임시 스크립트에는 반드시 UA 를 넣어라.★
- ★실패를 보면 ★더미 키 대조군★을 같이 돌려라. 둘 다 실패하면 키가 아니라 ★내 호출 방식★이 원인이다.
  2026-10-10 에 네 가지 키 조합이 전부 400 이라 "키가 죽었다"로 오진했는데, 더미 키도 같이 400 이었다.★
