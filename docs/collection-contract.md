# 수집 계약 — 개장 전·마감·주간 세 리포트 공통

이 문서는 **세 회차가 같은 방식으로 데이터를 모으게 만드는 단일 계약서**다.
회차마다 다른 것은 프리셋과 기준일 한 줄뿐이다. 나머지는 전부 동일하다.

각 회차 프롬프트에는 이 문서를 가리키는 12줄짜리 동일한 블록만 들어간다.
수집 방식이 바뀌면 **프롬프트 세 개가 아니라 이 문서 하나를 고친다.**
`docs/kiwoom-report-playbook.md`는 이 계약의 부속 문서로, 응답 필드와 해석 규칙을 담는다.

---

## 0. 회차별로 다른 단 한 줄

| 회차 | 프리셋 | 기준일 | 항목 수 |
| --- | --- | --- | --- |
| 개장 전 브리핑 (평일 06:00) | `--preset premarket` | 직전 거래일 | 81 |
| 마감 리포트 (평일 18:05) | `--preset close` | 당일 | 90 |
| 주간 리뷰 (토 06:00) | `--preset weekly` | 지난주 금요일 | 70 |

기준일은 **반드시 달력이 아니라 실제 거래일로 확정하라.** 휴장일(추석·설·대체공휴일)이
끼면 직전 거래일이 하루 앞이 아니다.

## 1. 절차 — 다섯 단계, 순서를 바꾸지 마라

### ① 계약서와 플레이북을 먼저 읽는다

```
curl -fsSL https://raw.githubusercontent.com/gihojeong/MyOwn/master/docs/collection-contract.md
curl -fsSL https://raw.githubusercontent.com/gihojeong/MyOwn/master/docs/kiwoom-report-playbook.md
```

두 문서가 프롬프트보다 최신이다. 충돌하면 문서가 이긴다.

### ② 5초 게이트 — 수집기를 띄우기 전에 두 줄로 환경을 본다

```
env | grep -c '^APP_'
python3 scripts/kiwoom_collect.py --check
```

- 첫 줄이 `0`이면 자격증명 미주입이다. 6분을 헛기다리지 말고 즉시 웹 경로로 전환하고
  그 사실을 리포트 말미에 적는다.
- 둘째 줄의 `token_issued`가 `true`가 아니면 에러 문자열 원문을 그대로 기록한다.
  추정으로 바꿔 적지 마라.
- **도달성을 맨 경로(`/`)로 확인하지 마라.** 키움 WAF가 TLS 직후 리셋해 `000`이 나오고,
  이그레스 차단으로 오진하게 된다. 판정은 실제 엔드포인트 1회 호출로 한다.

### ③ 수집기를 백그라운드로 먼저 띄운다 (2~6분)

```
python3 scripts/kiwoom_collect.py --preset <PRESET> --date <YYYYMMDD> --pause 0.25 --out kiwoom.json
```

돌아가는 동안 Drive 읽기(예측 계보)와 요인용 웹 검색을 **병렬로** 진행한다.
수집기가 끝날 때까지 기다리며 노는 시간은 없어야 한다.

### ④ 결과 JSON을 Read 도구로 열지 마라

close 기준 약 6MB다. 컨텍스트가 날아간다. python 한 줄로 필요한 키만 뽑는다.

```
python3 -c "import json;d=json.load(open('kiwoom.json'))['results'];print(d['index_kospi']['data']['cur_prc'])"
```

### ⑤ `summary.failed`에 남은 항목만 웹으로 보완한다

- **성공한 항목을 웹에서 다시 찾지 마라.** 시간 낭비이고 값이 어긋나면 혼란만 는다.
- 웹 수치가 API 확정치와 어긋나면 **API가 옳다.** 차이는 각주로 남긴다.
- 2026-09-24 실측: 웹이 SOXX를 564.27(−1.49%)과 565.72(−1.23%)로 두 번 다르게 줬고
  키움이 565.72/−1.23%로 확정했다. 이런 경우가 드물지 않다.

## 3. 종가는 KRX, 시세는 키움

키움의 `cur_prc` 계열은 **NXT(넥스트레이드) 체결(15:40~20:00)을 포함**한다.
따라서 정규장 종가가 아니다. 2026-09-23 관심종목 8개 전수에서 KRX 확정치와 어긋났다
(최대 두산에너빌리티 +1.224%, 최소 SK하이닉스 +0.054%, 방향도 일정하지 않다).

- **종가·시가총액·상장주식수는 KRX 확정치를 쓴다.**
- 키움 시세와의 격차는 버리지 말고 **개장 전 갭 신호로만** 쓴다.
- 실전 키가 들어오면 거래소 접미사 규약(`005930_NX` / `_AL`)을 재시험해 이 우회를 없앤다.

## 4. 실패를 다섯 가지로 가른다 — 섞어 적지 마라

| 에러 문자열 | 정체 | 조치 |
| --- | --- | --- |
| `KRX_AUTH_KEY가 없습니다` | 환경변수 미등록 | 등록 확인 |
| `KRX 서비스 미신청(...)` (401) | 이용 신청 미승인 | 신청 |
| `KRX 응답에 데이터가 없습니다` (200 + 0행) | 당일 미게시 | **손댈 것 없음** |
| `CONNECT tunnel failed, 403` (exit 56) | 이그레스 게이트웨이 차단 | 네트워크 정책 |
| `1504 해당 URI에서는 지원하는 API ID가 아닙니다` | **모의투자 미제공 API** | 경로 문제 아님 |

마지막 항목이 특히 함정이다. 문구가 URI를 지목하지만 경로는 스펙과 일치한다.
같은 URI의 다른 api-id를 한 번 쏴 보면 갈린다 — 그것이 성공하면 mockapi에 그 api-id만
없는 것이고, 고칠 코드가 없다. 2026-09-24 기준 `ka10087`(시간외단일가)과
`ka10098`(시간외등락률순위)이 여기 해당한다. 시간외는 지수 산출 비반영이므로
**결산 영향 낮음**으로 처리한다.

`exit 35`(서버 리셋)와 `exit 56`(게이트웨이 403)은 둘 다 `http_code=000`으로 보인다.
코드만 보고 합치지 마라. 프록시 원문 사유는 다음에서 읽는다.

```
curl -sS "$HTTPS_PROXY/__agentproxy/status"    # recentRelayFailures
```

## 5. 금지

- 자격증명(`APP_KEY` / `APP_SECRET` / `KRX_AUTH_KEY` / `ECOS_API_KEY`)의 **값을 출력하지 마라.**
  유무와 길이만 적는다. 파일·문서·커밋·프롬프트 어디에도 값을 쓰지 마라.
- 주문 도구를 쓰지 마라. `KIWOOM_MODE`는 읽기만 한다.
- 점검·시험 회차는 `kospi_forecast_*`를 만들지 마라. 월요일 회차가 그 계보를 읽는다.
- 기억이나 추정으로 숫자를 쓰지 마라. 경로를 다 돌린 뒤에도 없는 것만 "확인 불가"다.
