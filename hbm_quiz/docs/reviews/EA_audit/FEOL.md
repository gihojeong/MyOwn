## 판정 요약: **합격 (수정 2건 후 확정)**
가장 우려했던 **해설 ①–④ 번호 대응**은 무작위 표본 13문항(초·중 9, 고급 4) 전부 정확했습니다(전력: 원본 다수 문항이 번호를 어긋나게 서술). 계산 6문항(Black·Ea·Stoney·KOZ 2·RC) 전부 일치하며 오답이 모두 재현됩니다. base die 로직 공정 전환은 [V] 업체 발표 수준으로만 쓰였고 [R] 노드 소문은 정답 근거에 없습니다. 수정은 HCB pad 문항의 설계 조건(기하학적으로 틀림) 하나와 오답 질 하나입니다.

## 3. base die 로직 공정 전환 — 출처 수준 판정: **적정**
- FEOL-I-9027: "업체 발표로 나왔다" 로 지문을 한정, `src` = SK hynix–TSMC HBM4 협력 발표(2024-04, [V]) + JESD270-4 2,048 bit([S]). 정답 근거(2,048 I/O PHY·로직의 저전력 구현)는 발표 취지(성능·전력·고객 맞춤)와 맞음.
- FEOL-A-9017: 12 nm급/5 nm급 후보를 "이 문항의 가정, 상대값" 으로 명시한 표 판정형 — 업체 노드를 사실로 주장하지 않음 ✓. Samsung base die 4 nm(F18)는 THERM 쪽 src 에만 있고 FEOL 정답 근거로 쓰지 않음 ✓.

## 4. 수정 지시 (FEOL 에이전트)
| id | 문제 | 지시 |
|---|---|---|
| **FEOL-A-9013** | 설계 조건 "overlay ±0.5 µm 에서 pad 면적의 절반 이상이 겹치려면 지름 ≥ 3 µm" 가 기하학적으로 틀림. 두 원(지름 D) 중심이 0.5 µm 어긋날 때 겹침 비율은 D = 2 µm 에서 **68.5 %**, 대각 최악(0.71 µm)에서도 **55.9 %** 로 이미 절반을 넘음. 전문가가 즉시 반박할 수 있는 전제 | 조건을 **"대각 최악 어긋남 0.71 µm(±0.5 µm × √2)에서 겹침 ≥ 70 % → 지름 ≥ 3 µm"** 로 바꾸면(D = 3 µm 70.3 %, 2.5 µm 64.5 %) 표·정답(5 µm)이 그대로 성립. 해설에 두 원 교차 면적 근거 한 줄, 또는 '절반' 같은 물리 서술 없이 "(설계 규칙) 지름 ≥ 3 µm" 로만 줄 것 |

## 6. 커버리지
- 브리프 공백(DRAM 셀 BCAT·캐패시터·high-k, HKMG, EUV·확률 결함, base die 로직, via-middle 열예산, low-k CPI)이 신규 97문항으로 채워짐. 고급 37 → 59(브리프 목표 80 에는 못 미치나 질 우선 방침상 수용).
- **보강 권고(다음 차수, 고급 4–5)**: ① via-middle TSV 공정의 열예산(Cu 어닐·BEOL 400 °C)과 소자 Vt 이동 데이터 해석 1, ② low-k CPI crack — 적층 TC 후 crack 위치(코너·TSV 주변)로 원인층 특정 1, ③ EUV 확률 결함 Poisson 수율(via 개수 × 결함 확률)과 dose 상충 1, ④ DRAM 캐패시터 종횡비·유전막 두께·누설의 3변수 트레이드오프 1–2.
