## 4. 고급 비율(29 %) 판정: **적정 (하한 근접)**
- 브리프 권장은 30–35 % 이나, 고급 15문항을 "단일 지식" 이라 중급으로 재발급한 결과로 남은 고급 68문항은 모두 2단계 이상(외삽·추출·분포·원인 귀속) 문항입니다. 수를 맞추려고 약한 문항을 고급에 두는 것보다 낫습니다.
- 권고(다음 차수, 5–8문항): **nanoprobing 0건**과 **OBIRCH 고급 0건**이 남은 공백입니다. LIT 위치 + EOTPR 지연 + XRM slice 를 결합해 TSV open 위치·깊이를 확정하는 사례형 고급, nanoprobing 으로 base die 트랜지스터 누설을 확정하는 사례를 추가하면 고급 31–33 % 가 됩니다.
