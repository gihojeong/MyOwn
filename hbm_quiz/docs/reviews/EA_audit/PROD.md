대역폭·용량·높이·수율 계산이 전부 정확하고, STANDARDS 2.2(대역폭 식, base die 용량 제외, 높이 = base + N × (core + 간극), 높이는 '설계 조건')를 일관되게 지킵니다. FACT 정정 F04·F13·F17·F28·X-F9 가 모두 정확히 반영되었고, 반영 방식도 "틀린 서술을 오답으로 돌려 오개념을 직접 묻는" 형태라 좋습니다. W2-01/02(DRFM·on-die ECC) 판정과도 일치합니다.

## 3. 초급 35 % 비율 판정: **수용 (단 이후 추가는 중급·고급으로)**
- 권장(25–30 %)을 5 %p 넘지만, 남은 초급은 세대 사양(폭·채널·pseudo channel·전압·단수), 구조(PHY 위치, keep-out zone), RAS 용어(PPR·lane repair·DRFM·on-die ECC)처럼 **제품 분야의 기본 어휘**이고 대부분 "잘못된 통념"을 오답으로 둔 판별형이라 질이 낮지 않습니다(B-0001 "채널이 늘었으니 폭이 좁아졌을 것" 등). 수를 맞추려고 좋은 초급을 지우지 않습니다.
- 대신 다음 차수 신규는 초급 0, 중급·고급만(아래 §5).

## 4. 삭제 표본 (16건 대조) — **개념 손실 없음**
용량 가족(B-0008·I-0010·I-0016·A-0012 — 20단은 규격 밖, 남은 용량 문항은 24/32 Gb·12/16-Hi), 일반론 판단 태도(A-0026·A-0034·A-0044·I-0042·B-0059·B-0093), 공정 순서 회상(B-0089·B-0055 — COW/MOLD 소관), [R]·발표 회상(B-0128 HBM4E 4 TB/s·B-0130 16 Gb/s → I-9003 대역폭 환산으로 대체), 이중 의문형(B-0095 → B-0001 로 흡수), 바디 바이어스(I-0046 — 제품 분야 고유성 없음, FEOL 소관). 보고서 사유와 일치.

## 5. 커버리지·보강 권고
- 브리프 공백이던 RAS(ECC·PPR·lane repair·DRFM 0 → 13), 전력·pJ/bit(0 → 9), custom HBM·로직 base die(2 → 6), 수율·KGSD(→ 9) 모두 채워짐. 높이 예산은 775 µm 를 '설계 조건' 으로만 쓴다는 F13 원칙이 전 문항에서 지켜짐.
- **보강 권고(다음 차수, 중급 2 + 고급 3)**: ① HBM4 PHY 의 채널 수 증가가 SoC shoreline(가장자리 길이)에 주는 영향 — A-9032 와 다른 판단(배선 밀도 vs interposer 층수) 1, ② 실효 대역폭(refresh·bank conflict·page miss)과 스펙 대역폭의 차이를 측정 표로 판정 1, ③ custom base die 에 로직을 넣을 때의 열·전력·시험(KGSD) 상충 1, ④ HBM3E→HBM4 전환에서 동일 용량 구성의 스택 수·전력·높이 3변수 선택 2(중급 1·고급 1).
