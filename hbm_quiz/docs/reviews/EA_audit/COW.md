- 감사: EA · 2026-11-21 · 대상: `data/04_COW.json` 210문항(B54/I84/A72), 보고서 `docs/reviews/COW.md`, 원본 `scratchpad/w2/COW/orig_04_COW.json`
- 자동 검사: 감사 시점 E 0 / W 0 (게이트 통과)

## 판정 요약: **합격 (경미 3건)**
D2W overlay 재설계가 정확합니다 — 원본의 1,000배 과대 변위·W2W 규모 반경을 die 반경(모서리 √(5² + 6²) = 7.8 mm)으로 바꾸고, 배율 성분(중심 0·거리 비례·반지름 방향)을 병진·회전과 구분하는 판정이 물리적으로 맞습니다. FACT X-F5(Advanced MR-MUF = 칩 제어 + 방열 EMC 1.6배)·X-F6(dummy bump 최대 4배 + EMC, Tj 14 °C)·F23(HCB 열저항 20 % 이상)·F32(HCB 의 nm 급 요구는 거칠기·recess, die 휨은 µm 급) 모두 반영되고 `src` 가 붙었습니다. HCB 설정(pad pitch 9 µm, bump·간극 없음, f_bond hcb 에 gap 없음)도 STANDARDS 2.4·XD F3 와 일치.
