## 4. N단↔간극 수 규약 위반

MET-I-0001 — 해설 '접합 간극 11곳' — 12단은 접합 12회(STANDARDS 2.5). 계산값은 '최상단 core–최하단 core 사이 N−1 간극' 으로 해석하면 성립합니다. 문구를 그 뜻으로 바꾸고 base 까지의 간극(N 개)과 구분해 쓰십시오.
