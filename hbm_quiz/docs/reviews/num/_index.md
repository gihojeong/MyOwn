# NUM 수치 계산 검증 — 분야별 요약 (_index)

- 작성: NUM · 2026-11-20 · data/ 읽기 전용 검증. 분야별 상세는 같은 폴더의 `CODE.md` 입니다(열 관련 WARP-* id 는 `THERM.md`).
- 대상 선정: 발문이 계산을 요구하거나 보기가 모두 수치이거나 보기 3개 이상이 수치+단위인 문항, 그리고 k=1 수치 그림으로 판정하는 가족. 이 기준에 걸렸지만 계산이 아니라 수치를 기억해 고르는 문항(업체 발표·규격 회상)은 '범위 밖' 으로 분리해 FACT 로 넘겼습니다.
- 방법: 계산 유형 50개마다 solver 를 작성해(scratchpad `num/solve.py`) 지문 수치를 파싱하고 정답을 다시 계산했습니다. 이어 정답 키, 보기 값, 반올림, 오답 간 구별, STANDARDS 2.2–2.4 현실 범위, 그림 params·metrics 의 정답 노출을 문항마다 대조했습니다(`num/run.py`, `num/gen.py`). 검증 1,805 문항 중 1,760 문항의 산술 키가 재계산과 일치해 파서와 식도 함께 교차 검증되었습니다(불일치 45 = COW 배율 28 + 정답 비유일 16 + MET-I-0001 1; 이와 별도로 키는 산술 일치하지만 근거 결함인 reticle 4건이 있음).
