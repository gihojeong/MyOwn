## 4. 분야 간 사실 충돌

| 충돌 | 이 분야 관련 id | 무엇이 다른가 | 지시 |
|---|---|---|---|
| F2 N단의 간극 수가 분야마다 다름 | MET-I-0001 | THERM 열저항 가족은 “12단 → 간극은 die 수보다 하나 적은 11개” 로 계산하고 f_therm.n 에 core 수를 넣어(그림이 base 를 빼고 n−1 간극으로 계산) 결과를 맞춘다. SIP 는 “core n 장이면 간극 n 개”, MET-I-0001 은 “접합 간극 11곳”. STANDARDS 2.5: N단 → 간극 N. | THERM: 간극 N 으로 재계산·f_therm.n=N+1(최하단 core 까지를 묻는 경우만 N−1 을 명시). MET-I-0001: 0.995¹² 로 재계산(≈ 74 %). DA: f_therm 고정 pill “간극 수는 die 수보다 하나 적다” → “간극 수 = core die 수” (EA_to_DA §7). |
