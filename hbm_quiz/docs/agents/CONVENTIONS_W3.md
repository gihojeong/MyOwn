# 분야 간 공통 가정값 (CONVENTIONS_W3)

- 작성: THERM FIX 에이전트 · 2026-11-21 (W3 수정 라운드 배치 1) · 근거 지시: XD `_xd_post.md` §5 사실 충돌 F2·F3·F4·F6, EA 감사 W3 항목 5
- 지위: STANDARDS 2.5 "분야 간 공통 가정값" 이 가리키는 문서. **이후 배치의 모든 분야는 이 범위 안에서 문항 설정값을 고르고, 지문에 값과 "가정(문항 설정값)" 을 명시한다.** 범위 밖 값을 쓰려면 지문에 사유를 적는다.
- 출처 등급 표기는 STANDARDS 2.1 과 같다([S] 표준, [V] 업체·학회 공식, [R] 보도). 아래 값 대부분은 **표준·공식 출처가 없는 물성 기반 추정**이며 그렇게 표시했다. 이런 값은 정답 근거("보고된 값", "업계 표준값")로 쓰지 말고, **문항이 주는 조건**으로만 쓴다.

## C1. 접합층·간극의 면적 열저항 (XD F2)

### 기준 범위 (1D 수직 열 경로, 단위 mm²·K/W = 1e-6 m²·K/W)

| 구성 | 기준 범위(가정 범위) | 기본값(권장) | 산출 근거(물성 기반 추정) |
|---|---|---|---|
| Si die (core 30–60 µm) | 0.2–0.5 | 40 µm ÷ 130 W/m·K ≈ **0.3** | k_Si 120–150 (STANDARDS 2.4). 간극 열저항에서 거의 무시됨(≈ 2–3 %) |
| BEOL(배선층, 수 µm) | 1–4 | 5 µm ÷ 2 W/m·K = **2.5** | low-k·SiO₂(1.4) 와 Cu 배선의 혼합 유효 k 1–3 가정 |
| **µbump 접합층**(TC-NCF·MR-MUF, solder µbump + NCF/EMC/underfill) | **3–20** | 10 µm ÷ 1.0 W/m·K = **10** | 간극 5–15 µm(STANDARDS 2.4), 수지 k 0.2–0.7(NCF·underfill)·0.7–3(EMC/MUF), µbump·dummy bump 면적률 수–20 % 의 병렬·확산 혼합 → 유효 k ≈ 0.5–2 W/m·K. 수지 단독(10 µm ÷ 0.4 = 25)은 상한 밖 — bump 가 없는 영역의 국부값으로만 쓴다 |
| **HCB 접합 계면층**(bond pad + bonding 유전막, BEOL 제외) | **0.2–2** | **1** | bonding 유전막(SiO₂·SiCN, 합계 1–3 µm, k ≈ 1.4)에 Cu pad(면적률 10–30 %)가 병렬. 유전막 단독 1–3 µm ÷ 1.4 ≈ 0.7–2, Cu pad 병렬로 그 이하. Si/유전막 계면 경계 저항(≈ 0.001–0.01)은 무시 가능 |
| 간극 합계 — µbump 방식 | 8–20 | **13** | 0.3 + 2.5 + 10 ≈ 12.8. 이 값에서 접합층이 약 78 % 로 지배 |
| 간극 합계 — HCB | 3–5 | **5** | 0.3 + 2.5 + 1–2 ≈ 4–5. 지배 층이 BEOL 로 바뀐다 |

### 사용 규칙
1. **비(µbump ÷ HCB 접합층) 는 5–20 배**, 간극 합계 비는 약 2.5–3 배가 되게 고른다. Samsung 의 "TC 본딩 대비 HCB 열저항 20 % 이상 개선, 16단 이상"(FACT F23, [V])은 **스택 전체(Si·BEOL·TIM 포함)** 기준 발표값이므로 간극 단위 비율(2.5–3 배)과 직접 비교하지 않는다. 문항에서 둘을 같은 양으로 놓지 말 것.
2. **병렬 혼합 근사(k_eff = Σ f·k)는 유효 k 의 상한(= 열저항의 하한)** 이다. Cu pad·µbump 가 면적의 일부만 차지하면 열이 pad 로 모이는 구속(constriction)·확산 저항과 계면 저항이 더해져 실제 저항은 병렬값보다 크다. 예: Cu 25 % + 유전막 75 % 의 병렬값 ≈ 99 W/m·K(1 µm 이면 ≈ 0.01 mm²·K/W)은 하한이며, 설계 계산에는 위 범위(0.2–2)를 쓴다. 직렬 근사(Σ f/k 의 역수)는 하한 k 다.
3. **"간극" 의 정의를 지문에 적는다**: "간극 하나 = Si + BEOL + 접합층" 인지, "접합층만" 인지. 간극 수는 STANDARDS 2.5(N단 → 간극 N, base–core1 포함).
4. 수지 단독 국부 저항, thermal dummy bump 밀도 변경 효과 등 범위 밖 값을 쓰는 문항은 "가정" 과 이유(예: bump 없는 가장자리, void 영역)를 지문에 적는다.
5. 열유속은 STANDARDS 2.4 대로 **문항 설정값**(THERM 은 0.10–0.20 W/mm², 120 mm² 면적에서 12–24 W/스택)으로만 주고 "보고된 범위" 로 쓰지 않는다(FACT F44).
6. 결과 온도: 최상단 core 60–70 °C 출발, 최하단 core·base 는 대략 75–100 °C 안에 들도록 설계한다(STANDARDS 2.4 비현실 결과 금지).

### 판정 die (STANDARDS 2.5 재확인)
- 85 / 95 °C 구간과 refresh 배수는 **최하단 core die(core 1)** 온도로 판정한다. 상부 냉각 1D 모델에서 core 1 = 최상단 core + (N − 1) × 간극 ΔT, base die = core 1 + base–core1 간극 ΔT.
- base die 온도는 로직 상한(설정값)·센서 판독 문제에서만 판정에 쓴다. base 센서 판독값으로 core 1 을 추정할 때는 base–core1 간극 ΔT 를 **빼야** 한다(열은 base → core 방향).
- SoC·이웃 스택 결합 계수(Ψ, K/W)를 주는 문항은 그 Ψ 가 **어느 die 의 온도**에 대한 것인지 지문에 적는다.

## C2. D2W HCB overlay 허용치 — pitch 와 함께 준다 (XD F3)

| 항목 | 기준 | 근거·등급 |
|---|---|---|
| HBM 용 D2W HCB 문항의 pad pitch | 6–15 µm(STANDARDS 2.4 의 설정 2–15 µm 중 HBM 맥락) | SK hynix 발표 "HB 접합 pitch 18 µm 미만" [V-2차] |
| overlay 허용치(설계 기준) | **pitch 의 약 5–10 %**(예: 10 µm pitch → ±0.5–1 µm, 6 µm → ±0.3–0.6 µm) | 위·아래 pad 크기를 다르게 두는 설계에서 허용 offset ≈ (큰 pad − 작은 pad) ÷ 2. pad 지름 ≈ pitch 의 40–60 % 가정에서 산출한 **가정 범위**(문헌 고정값 아님) |
| 장비 정렬 능력(3σ) | D2W ±0.1–0.5 µm 급 | imec 2 µm pitch D2W 시연 overlay < 350 nm(ECTC 2024) [V]; 장비 업체 사양은 [V]/[R] 혼재 — 정답 근거로 특정 수치 단정 금지 |
| ±50–100 nm 급 | **W2W 또는 sub-µm–2 µm pitch 맥락** 에서만 | D2W HBM(≥ 6 µm pitch)에 ±50 nm 허용치를 쓰면 pitch 대비 0.5 % 로 과도하게 엄격 |

- 규칙: overlay 허용치·측정값을 쓰는 문항은 **반드시 pad pitch(가능하면 pad 지름)를 함께** 준다. 오차 합성 방식(선형 합 vs RSS)을 지문에 적는다 — 독립 요인이면 RSS, 같은 방향 계통 오차(배율·회전·열팽창)는 선형 합.
- `f_hcb` 는 pitch ≤ 10 µm 만 그린다. 그보다 크면 `f_table`/`f_note`.

## C3. HBM 스택 폭·간격과 SoC 변당 스택 수 (XD F4)

| 항목 | 기준(문항 설정값) | 근거·등급 |
|---|---|---|
| HBM3E 스택 외형 | **11 × 11 mm** 로 가정 | 업계 통념 [R] — JEDEC 외형 표 미열람(FACT §0) → "가정" 명시 |
| HBM4 스택 외형 | **12.8 × 11 mm** | SK hynix Hot Chips 2026 제품 치수 [V-2차](FACT F13) — "업체 발표 기준" 명시 |
| 스택–스택 간격 s | **0.5 mm**(설정 0.2–1 mm) | interposer 배치 여유·underfill fillet 가정 — 표준값 없음 |
| SoC–HBM 간격 | 0.5–2 mm(열 결합 문항의 설정값) | 가정 |

- 변당 스택 수 = ⌊(L + s) ÷ (w + s)⌋. **경계 사례를 피한다**: L 이 n·w + (n−1)·s 의 ±1 mm 안에 들면 간격 가정 하나로 답이 바뀌므로(예: 33 mm 변에 11 mm 스택 → 간격 0 이면 3개, 0.5 mm 면 2개) 그런 L 을 쓰지 않거나, 그 민감도 자체를 묻는 문항으로 만든다.
- 스택의 어느 변(11 mm / 12.8 mm)이 SoC 변을 따라 놓이는지 지문에 적는다.

## C4. µbump·배선 EM 의 기본 가정 (XD F6)

| 대상 | Ea 기본값(설정) | 문헌 범위(참고) | Black n |
|---|---|---|---|
| SnAg solder µbump(Cu pillar + 얇은 solder 포함) | **0.8 eV** | 약 0.6–1.1 eV(IMC 전환 정도·온도 구간에 따라 다름) | **2**(데이터로 n 을 뽑는 문항은 1–3) |
| Cu BEOL 배선·TSV(Cu/cap 계면 확산) | **0.9 eV** | 약 0.8–1.0 eV | 1–2 |

- 규칙: Ea·n 은 **항상 "설정값" 으로 지문에 준다**. 문헌 범위가 넓으므로 정답 보기로 "µbump 의 Ea 는 X eV 이다" 를 묻지 않는다. 데이터에서 Ea 를 추출하는 문항은 결과가 위 범위 안에 들게 설계한다.
- 같은 SnAg µbump 를 다루는 문항끼리 다른 Ea 를 쓰려면 이유(IMC 완전 전환, 다른 고장 기구)를 지문에 적는다.
- 전류 밀도는 STANDARDS 2.4(µbump 당 수십 mA 이하, 평균 10⁴ A/cm² 급이 EM 시험 영역).
