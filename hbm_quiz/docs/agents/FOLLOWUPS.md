# 최종 점검 전 확인 목록 (오케스트레이터)

- [THERM] 판정 여유가 작아 반올림·가정값에 민감한 문항: A-0033 (0.16 vs 0.167 W/mm²), A-9009 B안 core1 84.8 °C, A-9042 85.3 °C, A-9032 (82 % vs 81.9 %). 기준서상 근접 오답(3 % 미만) 규칙과 같은 취지로, 여유를 키우거나 경계 민감도 자체를 묻도록 재설계 검토 (EA 최종 점검).
- [THERM] CONVENTIONS_W3 C1 접합층 열저항 범위는 물성 추정 가정값 — 문헌값 확보 시 갱신.
- [SIP] A-9046 "LSI 에 TSV 없음" 은 문항 가정 — CoWoS-L LSI TSV 유무 공식 확인 필요 (FACT).
- [PROD] A-9032 를 CONVENTIONS_W3 C3 (간격·돌출) 규칙에 맞출 것 — 배치 3.
- [FEOL] A-9013: C2 적용(pitch 10 µm)으로 후보 지름 2/5/10 → 2/4/6 µm, 정답 5 → 4 µm 로 변경됨 — EA 원 지시("표·정답 유지")와 다르므로 EA 확인.
- [FEOL/MET/SAW] 가정값 문항: FEOL A-9037 ΔIon, A-9047 ΔVt, A-9050 누설; SAW A-9098 유효 가장자리 길이 비 4.
- [COW] nm 급 overlay 문항이 모두 미세 pitch(1.6–3 µm) 개발 조건으로 바뀜 — 현 HBM HCB pitch(6–15 µm) 조건 overlay 문항이 I-9022 하나뿐. 균형 검토.
- [DA] f_stack 주제도(k=0)가 기본 간극 "7 µm" 를 그려 지문(10 µm 등)과 다름 — 기본 수치 숨김 옵션 또는 k=0 시 수치 생략.
- [PROD] I-9047 spacer 방식은 업체 공식 미확인(가정 표기).
